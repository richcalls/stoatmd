# StoatMD Logo 方向草案

候选名 **StoatMD**（域名 stoatmd.com 可注册，尚未最终定名）。  
色板对齐风格 B：暖纸 `#F7F3EB` · 主色 `#1C1A18` · 点缀 `#3D5A80`。  
字标字体：**Instrument Sans**（克制无衬线，非 Inter）。矢量源 + PNG；遵循 [impeccable](sand-workflow:impeccable)。

> **App Icon 画布约定（Dock 视觉补偿版）：** 画布 **1024×1024**；内容网格 **920×920** 居中；四周透明边 **52px**；圆角板仍按 `rx=234`（≈22.85%，相对 1024 画布，920 下实际约 210）。SVG 外层为 `translate(52 52) scale(920/1024)`，内层 `clipPath`/`rect` 继续用 `rx=234`（随外层等比缩放）。  
> **为什么不用 Apple 模板的 824/100：** 模板 + 系统 App 的底板只占画布 80.5%。对照正海 Dock 截图做亚像素实测：我们 41.1px vs 邻居 TickTick 41.6px，**几何尺寸其实一样**；但深色底板在 Dock 里有「暗色显小」的错觉（同尺寸暗色物体看起来更小），且邻居都带红色角标。因此按**视觉**补偿，把底板放大到 **920（80.5%→89.8%，+11.6%）**，Dock 里才会和普通第三方 App 观感等大。**不要改回 824**，也不要再按“模板尺寸”回退。  
> **模板投影不可省：** 30% 黑、`stdDeviation=14`、`dy=8`（SVG `feDropShadow`，PNG 用等价的模糊黑 alpha）。投影会伸进透明边，导出 PNG 的 alpha 可见范围约 **980–982**（头像组 980，织线/敏捷 982），四边 alpha 为 0、不得裁切。没有投影时 Dock 里会发平、更显小。  
> ~~「满幅 1024、无额外外边距」是错的~~（见 PR #40）——满幅底板会比邻居大一圈；正确目标是 920 视觉补偿值。

> **入库范围（正海）：** 方向 **B · S 字交织**（`02-s-weave/`）已砍，不入库。  
> 当前仅保留 **A · 织线白鼬** 与 **C · 敏捷剪影**（PNG + SVG），暂留再比，择一作主方向。

> **接入状态（v2）：** 两套 Logo 各有浅色 / 暗色版本（`docs/brand/stoatmd-logo/app-icons/*.svg` → `assets/app-logos/{thread,thread-dark,agile,agile-dark}.png`）。  
> 源 SVG 与 PNG 均按上面的 Dock 视觉补偿栅格：920 内容 + 52px 透明边 + `rx=234`（相对 1024）+ 模板投影，Dock 视觉尺寸与普通第三方 App 对齐。  
> 默认 **A · 织线白鼬**；设置 → 外观 → 应用图标可切到 **C · 敏捷剪影**，立即更新 macOS Dock / 窗口切换器图标并记住选择（`prefs.appLogo`），重启后恢复；图标随当前主题明暗自动选浅色 / 暗色版本。

> **头像组（草案 · `04-head/`）：** 正海本地对比用的三套头像 App Icon——**A 冬白侧脸** / **B 棕白侧脸** / **D ¾棕白**。  
> 无织线领；单色深底 `#1C1A17`（约 rgb 28,26,23）；不要正圆背景，须套 **macOS 圆角板**（四角透明），保留 **52px** 透明边、**920** 内容网格与**模板投影**。运行时 id 为 `head-a` / `head-b` / `head-d`（`assets/app-logos/head-{a,b,d}{,-dark}.png`）；当前品牌仅暗色，light/dark 暂同图。  
> **保留**原 thread / agile 可选，默认仍为 thread。

## A · 织线白鼬（`01-thread/`）

**概念：** 连续细线勾出细长侧身白鼬；体内两道靛蓝织线像笔记页栏分隔；左边距双线呼应编辑器织线。

| | |
|--|--|
| **优** | 与现有 Loom/Stoat UI「1px 织线」语言最贴；动物名可感；浅深/单色都干净 |
| **劣** | 小尺寸（通知栏 / 设置列表）线稿识别弱于实心剪影；须保持「鼬」而非「云/叶」比例 |

**首选理由：** 品牌与产品表面同一套语法，定名 Stoat 时叙事最顺。

## C · 敏捷剪影（`03-agile/`）

**概念：** 实心几何侧影（三角耳 + 流线身 + 扬尾）；底下一根靛蓝织线锚点；字标干净。

| | |
|--|--|
| **优** | 小图标识别最好；「短、敏捷」气质强；制作 App Icon 成本低 |
| **劣** | 实心块与 UI 细线语言略脱节；过简时易被看成泛鼬/猫科剪影 |

## 给正海的看片顺序建议

1. **先看织线 A / 敏捷 C**（品牌主方向）  
2. 再对比 **头像组 A / B / D**（本地切换 Dock 看真实尺寸）  

也可 **织线 A 作完整品牌（字标+营销）+ 头像或敏捷作小尺寸 App 图标变体**，但 v1 建议先定一个主方向再衍生。
