# StoatMD Logo 方向草案

候选名 **StoatMD**（域名 stoatmd.com 可注册，尚未最终定名）。  
色板对齐风格 B：暖纸 `#F7F3EB` · 主色 `#1C1A18` · 点缀 `#3D5A80`。  
字标字体：**Instrument Sans**（克制无衬线，非 Inter）。矢量源 + PNG；遵循 [impeccable](sand-workflow:impeccable)。

生成：`src/generate_v2.py`（CairoSVG 栅格）。

> **入库范围（正海）：** 方向 **B · S 字交织**（`02-s-weave/`）已砍，不入库。  
> 当前仅保留 **A · 织线白鼬** 与 **C · 敏捷剪影**（PNG + SVG），暂留再比，择一作主方向。

---

## A · 织线白鼬（`01-thread/`）

**概念：** 连续细线勾出细长侧身白鼬；体内两道靛蓝织线像笔记页栏分隔；左边距双线呼应编辑器织线。

| | |
|--|--|
| **优** | 与现有 Loom/Stoat UI「1px 织线」语言最贴；动物名可感；浅深/单色都干净 |
| **劣** | 小尺寸（通知栏 / 设置列表）线稿识别弱于实心剪影；须保持「鼬」而非「云/叶」比例 |

**首选理由：** 品牌与产品表面同一套语法，定名 Stoat 时叙事最顺。

---

## B · S 字交织（已砍 · 不入库）

原 `02-s-weave/`：几何字母 S 穿过三股织线。正海反馈识别不清，**已砍**；本目录无对应资产。

---

## C · 敏捷剪影（`03-agile/`）

**概念：** 实心几何侧影（三角耳 + 流线身 + 扬尾）；底下一根靛蓝织线锚点；字标干净。

| | |
|--|--|
| **优** | 小图标识别最好；「短、敏捷」气质强；制作 App Icon 成本低 |
| **劣** | 实心块与 UI 细线语言略脱节；过简时易被看成泛鼬/猫科剪影 |

---

## 给正海的看片顺序建议

1. **先看 A**（织线衔接 + 命名叙事）  
2. 若觉得线稿太弱 → **C**  

也可 **A 作完整品牌（字标+营销）+ C 作小尺寸 App 图标变体**，但 v1 建议先定一个主方向再衍生。
