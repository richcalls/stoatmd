# LoomMD v1 UI 设计说明

> 风格 **B**：轻与原生 + Loom「织线」隐喻  
> 公开署名：forecho · 文案语言：中文  
> 日期：2026-10-29（Asia/Shanghai）

## 1. 设计意图

LoomMD 是本地 Markdown 笔记本：自选文件夹、普通 `.md`、源码编辑 + 可切换/分栏预览（非 WYSIWYG）。  
视觉对标「轻、原生、专注书写」，借鉴妙言的留白与安静，但用 **织线** 建立自己的识别：

- 栏与栏之间是 **1px 细线**，不是粗分割条
- 顶栏可有一条极细水平织线装饰
- 选中态 = 淡靛蓝底 + **左侧细织线**，不用大色块
- 强调色克制，图标线性，工具栏极少

不要 Electron 厚重阴影，不要 ExpireMate 的 lime/cyan。

## 4. 栏宽（Mac 1440×900 内容区）

窗体内容区约 1440×900（含标题栏 52px）：

| 栏 | 宽 | 说明 |
|----|----|------|
| 左·文件夹树 | 200px | 底栏留灰显「同步…」v2 入口 |
| 中·笔记列表 | 280px | 顶：搜索 + 文件夹名 + 新建 |
| 右·编辑/预览 | 剩余 ≈ 960px | 分栏时 1:1；顶工具条高 40px |

细线分隔：左|中、中|右、编辑|预览 均为 1px `--thread`。

## 5. 交互说明（v1）

### Mac
- **三栏固定**：树 / 列表 / 编辑区；栏宽可后续拖拽（稿面先静态）
- **右栏模式**：仅编辑 · **分栏**（默认示意）· 仅预览；分段控件在工具条左侧
- **源码编辑**：等宽字体 + Markdown 语法着色；非 WYSIWYG
- **预览**：只读渲染，与源码同步滚动（稿面静态对齐）
- **搜索**：中栏顶部，过滤当前文件夹笔记
- **新建**：中栏右上 `+`
- **设置**：工具条齿轮，打开偏好（字体、主题跟随系统等）

### iPhone
- 导航栈：文件夹 → 列表 → **编辑页**（本稿）
- 顶栏：`‹ 写作` | 标题「写作的框架」| 「已保存」
- 分段：`编辑` | `预览`（本稿在编辑）
- 键盘可省略；可选底栏极简格式提示（`#` `**` `` ` `` `>` `-`）
- 无底部 Tab（编辑页沉浸）；列表页另议

### iPad
- 接近 Mac 三栏；窄屏折叠为双栏。v1 稿未单独出屏，结构复用 Mac。

## 8. 与妙言的差异（刻意）

- 强调色：靛蓝织线，而非妙言绿叶
- 右栏默认 **分栏预览**，明确「源码 ≠ 所见即所得」
- 选中态左侧细线，强化 Loom 隐喻
- 左栏底预留同步灰显，产品叙事不同
