# StoatMD · PRODUCT

> 模式：**Operate**（本地写作工具，任务优先）  
> 定名：**StoatMD** · 域名：stoatmd.com（可注册）  
> 曾用名：LoomMD（内部/早期代号；仓库路径 `loommd` 暂保留）  
> 署名：forecho · 仓库：https://github.com/richcalls/loommd  
> 定稿：2026-10-29（Asia/Shanghai）

## 产品是什么

StoatMD（白鼬 / stoat）是本地 Markdown 笔记本。用户自选本机文件夹，读写普通 `.md` 文件；源码编辑，可切换或分栏预览——**不是**所见即所得。

首发平台：macOS + iOS（iPad 接近 Mac 三栏）。公开署名 forecho。

## 谁在用、在干什么

写作者、笔记爱好者。场景：打开本地库 → 找一篇笔记 → 写源码 → 偶尔看预览。工具应消失在任务里，不为「设计感」打断书写。

## 核心结构

| 平台 | 布局 |
|------|------|
| Mac | 三栏：文件夹树 / 笔记列表 / 编辑+预览；**三栏可折叠**（VS Code 式：左栏→图标轨或藏起、中栏可收，折叠后编辑区占满） |
| iPhone | 导航栈：文件夹 → 列表 → 编辑页 |
| iPad | 近 Mac；窄屏可折双栏（v1 稿不单独出屏） |

右栏模式：仅编辑 · **分栏（Mac 默认）** · 仅预览。非 WYSIWYG。

Mac 编辑工具条：左侧 `SidebarSimple`（文件夹侧栏）· 笔记列表开关；右侧 `Code` · `Split` · `Eye` | `TextT` · `Gear`。**无**独立 Palette 入口。控件以图标为主（出海多语言，tooltip 中英均可）。

## 设置 · 主题 · 字体（v1）

入口：**Gear → 设置**（TextT 可直达字体相关；主题只在设置里）。

| 能力 | 说明 |
|------|------|
| 主题 | 只换颜色的预设色板（参考 Slack 外观网格），**不**换布局、不做自定义色板编辑器；完整 hex 见 `DESIGN.md`，**不必**为每套出图 |
| 字体 | 正文字体（系统 UI / 宋体类 / 等宽）、字号步进、行高；一行真文案预览。源码区仍用等宽 |
| 同步 | **正式核心能力**：设置 → 同步；一期仅 Google Drive / Dropbox（均主推，Agent 友好）；一点「开启同步」付费墙（未付费不走 OAuth）；冲突必弹 |

预设 **12** 套（light / dark 标明模式；实现按 token 切换）：
- **Light（8）**：织线纸白（默认）、**纯白**（`#FFFFFF` 必选）、鼠尾草、墨灰、砂褐、雾蓝、樱雾、青瓷
- **Dark（4）**：暖夜炭（默认）、靛蓝浓、暮紫、松烟

色号与全量 token 以 `DESIGN.md`「主题预设」为准；设置页网格仅为示意。

## 付费与版本边界

| 能力 | v1 | 说明 |
|------|----|------|
| 本机读写 `.md` | 免费、默认可用 | 主路径 |
| 同步买断 | v1 正式 | 一点「开启同步」即墙；未付费不走 OAuth；详见 `SYNC-FLOW.md` / 仓库 `docs/product/SYNC.md` |

不要在主路径放大 Banner 或付费墙打断写作。

## 文案语气

中文。安静、短、说清动作。控件命名动作（搜索笔记、仅编辑、已保存）。错误说问题与恢复方式（实现阶段再补）。

## 图标

界面线性图标主用 **Phosphor**（Light / Regular）。稿面可用线性 SVG 占位；实现时对照附录映射表换成 Phosphor 名。

## 不做（本定稿）

- App 图标 / 营销页（另开）
- **MCP（已砍）**：无自有服务器，远程 Agent 无法挂本地 MCP——设置导航与灰显入口已移除；决策保留于此
- 多库、标签体系深设计（同步已升正式，见 SYNC-FLOW）
- WYSIWYG、实时协作
- 自定义主题编辑器 / 布局皮肤（主题仅预设色板）
- 顶栏独立 Palette 入口（主题归设置）

## 语言与市场

多语言、面向出海。UI 至少中英（跟随系统 / 手动优先规则与 ExpireMate 网站类似时可复用）；产品与同步文案勿默认「仅中文用户」。主推 Google Drive / Dropbox 也服务全球用户。
