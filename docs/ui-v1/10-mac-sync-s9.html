写作的框架

为什么需要框架

好的文章不是灵感的堆砌，而是结构的展开。框架让读者知道自己站在哪里，也让作者知道下一步写什么。

三个层次

  • 骨架：论点与顺序
  • 肌肉：例证与细节
  • 皮肤：语气与节奏
先写骨架，再填血肉。
润色永远放在最后。

在编辑器里用 Cmd + B 加粗，用 斜体 强调语气。
