# StoatMD · 云盘同步流程规划

> 设计 / 产品向 · 正式能力（非「即将推出」占位心态）  
> 产品定名：**StoatMD**（曾用名 LoomMD）· 本地优先 · **不自建服务器** · 定稿目录旁文档  
> 日期：2026-10-29（Asia/Shanghai） · 署名：forecho / 正海 + 产品经理已定约束

---

## 1. 目标与非目标

### 目标

| # | 目标 |
|---|------|
| 1 | 用户可选地把**本机库文件夹**与某一云盘里的远程库对齐，跨 Mac / iPhone（及后续 iPad）读写同一套 `.md` |
| 2 | **本机文件夹仍是真相**：App 永远先读写本地；同步是对齐手段，不是「云端才是主库」 |
| 3 | **零自建后端**：授权、传输、冲突元数据都走提供商 SDK / 系统能力，我们不托管用户笔记 |
| 4 | **主推 Google Drive、Dropbox**：方便用户自己的 Personal Agent（及脚本）直接操作同一路径 |
| 5 | **不做 iCloud**：正海定稿；同步一期仅 Google Drive + Dropbox |
| 6 | 流程按**完整能力**设计；付费墙只挡「开启/连接」入口，不偷工减料状态机 |

### 非目标（本规划不做）

| # | 非目标 |
|---|--------|
| 1 | 自建账号体系、自建同步服务器、实时协作编辑 |
| 2 | 多用户共享同一库、细粒度权限、评论线程 |
| 3 | 把云端当作唯一真相、静默覆盖本地 |
| 4 | 一期做完所有国内盘（坚果云等）与 OneDrive 的完整打磨（可灰显二期） |
| 5 | 支持或承诺 iCloud（正海：不做） |

## 3. 用户旅程

本地免费可用；同步是可选核心能力。付费墙卡在「开启同步 / 添加连接」入口（见开放问题），流程本身按已解锁设计。

### 3.1 首次开启 → 日常

| 步 | 用户动作 | 系统行为 | UI 要点 |
|----|----------|----------|---------|
| 0 | 正常使用本机库 | 仅本地读写 | 侧栏无强制同步 Banner |
| 1 | 设置 → **同步** →「开启同步」或「添加云盘」 | 若未付费：先出示付费墙入口，通过后继续 | 能力区完整；墙只挡连接 |
| 2 | **选提供商** | 展示矩阵；GDrive/Dropbox 均标「推荐 · Agent 友好」 | 一期仅两项 |
| 3 | **授权** | 系统 / OAuth 浏览器或系统账号表；App 仅存 token（钥匙串） | 「授权中」全屏/sheet；可取消 |
| 4 | **选/建远程库文件夹** | 列出云端目录；可「新建 StoatMD 库」；绑定后写入本地偏好：`provider + remotePath + localRoot` | 强调：本地根目录不变，只是多了一条对齐通道 |
| 5 | **首轮同步** | 双向扫描 → 上传缺失、下载缺失；进度（文件数 / 字节） | 「同步中」；可后台；失败可重试 |
| 6 | **日常** | 保存后防抖上传；启动 / 回前台 / 手动刷新拉取；状态点进侧栏与设置 | 默认安静：已同步只显示小状态 |

### 3.2 文案原则（提供商相关）

| 场景 | 推荐说法 |
|------|----------|
| GDrive / Dropbox | 「推荐 · 方便你的 Personal Agent 读写同一库」 |
| 未连接 | 「本机库始终可用。同步是可选能力。」 |

## 4. 状态机

单一连接维度（一期默认一库一连接；多连接若以后要做，另开）。

| 状态 | 含义 | 侧栏 / 设置表现 | 可转至 |
|------|------|-----------------|--------|
| **未连接** | 未绑定任何云盘 | 「未开启同步」+ 开启按钮 | 授权中（点开启） |
| **授权中** | OAuth / 系统账号进行中 | 转圈 + 取消 | 未连接 / 选文件夹（成功）/ 错误 |
| **同步中** | 首轮或增量传输中 | 旋转图标 + 简短进度 | 已同步 / 冲突 / 错误 / 离线 |
| **已同步** | 最近一次对齐成功 | 静默勾 / 「刚刚同步」相对时间 | 同步中（有变更）/ 离线 / 冲突 |
| **冲突** | 同路径两侧均有不可自动合并的改动 | 醒目但非恐吓：冲突数 +「处理」 | 同步中（用户抉择后）/ 已同步 |
| **离线** | 无网或提供商不可达 | 「离线 · 仅本机」；本地照常写 | 同步中（恢复后）/ 错误 |
| **错误** | 授权失效、配额、权限、路径丢失等 | 短错误 + 恢复动作（重新授权 / 重选文件夹 / 重试） | 授权中 / 未连接 / 同步中 |

```
未连接 → 授权中 →（选文件夹）→ 同步中 → 已同步
                ↘ 错误 / 未连接
已同步 ⇄ 同步中
已同步 / 同步中 → 冲突 →（用户选择）→ 同步中 → 已同步
任意已连接态 → 离线 →（恢复）→ 同步中
任意 → 错误 → 重新授权 / 重试 / 断开→未连接
```

**本地优先不变**：任何云状态异常时，编辑、保存、搜索本机库照常。

## 5. 冲突策略

**禁止静默覆盖。** 检测到「同相对路径、双方均有未对齐修改」→ 进入 **冲突**，用户显式选择。

| 选项 | 行为 | 适用 |
|------|------|------|
| **保留本地** | 以上传本地版本覆盖云端该文件 | 本机是准的 |
| **保留云端** | 以下载云端版本覆盖本地该文件 | 另一台设备刚改完 |
| **两边都留** | 保留本地；云端副本另存为 `原名 (云端冲突 yyyy-mm-dd).md`（或对称策略，见开放问题） | 不确定、两份都要 |

| 规则 | 说明 |
|------|------|
| 粒度 | **按文件**，不整库一刀切；可「全部应用同一选择」批量 |
| 文件夹增删 | 空目录冲突少见；有内容则按文件枚举 |
| 删除 vs 修改 | 一侧删、一侧改 → 冲突；选项同上（保留本地含「恢复删除」语义需在文案写清） |
| 自动合并 | **v1 不做** Markdown 三路合并 |
| 默认 | **不预勾任何覆盖项**；打开冲突表必须用户点选（默认策略见开放问题） |

## 6. Mac vs iPhone 入口差异

| 项 | Mac | iPhone |
|----|-----|--------|
| 主入口 | **设置 → 同步**（Gear）；侧栏底或库名旁小状态可点进设置同步段 | **设置**（系统式列表）→ 同步；编辑页不塞大入口 |
| 提供商选择 | 设置内 sheet / 子页；卡片网格（近主题网格密度） | 全宽列表行 + 推荐标签 |
| 授权 | 系统浏览器 / ASWebAuthentication；或 Google/Dropbox 官方流程 | 同上 |
| 选远程文件夹 | 可较大面板浏览路径 | 简化：最近 / 新建库 / 浏览 |
| 首轮进度 | 设置页内 + 可选菜单栏/侧栏轻提示 | 设置页内 + 本地通知（可选，勿吵） |
| 冲突 | 模态表 + 文件列表；可并排打开本地预览（若实现成本可控） | 列表 + 逐文件选择；预览用推入页 |
| Agent 引导 | 设置同步页底部：「要用 Agent 读写库？选 Google Drive 或 Dropbox」 | 同文案，更短一行 |

## 7. Personal Agent 说明（为何主推 GDrive / Dropbox）

| 维度 | Google Drive / Dropbox |
|------|------------------------|
| 云端 API / 挂载 | 成熟，Agent、脚本、CI 易接入 |
| 路径稳定性 | 远程文件夹 ID / 共享路径清晰 |
| 跨平台 | 强（含非 Apple） |
| StoatMD 立场 | **一期仅此二者**：同步 + Agent 同一真相路径；**不做 iCloud** |

产品一句话给用户：

> 笔记始终在你自己的文件夹里。接上 Google Drive 或 Dropbox 后，你的 Personal Agent 也可以读写同一库。
