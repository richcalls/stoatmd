# LoomMD 产品总述

> 本地优先 Markdown 笔记本 · 首发 macOS + iOS · **面向全球用户（出海）**  
> 日期：2026-10-29（Asia/Shanghai） · 产品约束：正海已拍板  
> 本文档以中文撰写，产品本身为**多语言、国际化**产品，非国内向。

## 一句话

**本机文件夹是真相**；普通 `.md` 随时可用。同步是可选但正式的核心能力——把本机库对齐到用户自己的云盘，**不自建服务器、不托管笔记**。

## 出海与多语言

| # | 约定 |
|---|------|
| 1 | **面向全球用户**：文案、定价入口、提供商矩阵均按出海产品设计，不按「国内向 App」叙事 |
| 2 | **UI 与产品文案多语言**：至少 **中文 + 英文**；语言选择 / 跟随系统按产品惯例（系统语言优先，设置内可改） |
| 3 | **同步提供商与出海一致**：主推 **Google Drive / Dropbox**，同时服务非中文用户与 Personal Agent；iCloud 服务 Apple 生态，不当 Agent 主路径 |
| 4 | 仓库产品文档可用中文维护；对外商店页、应用内字符串需具备对应本地化 |

## 产品原则

| # | 原则 |
|---|------|
| 1 | **本地优先**：App 永远先读写本机；同步是对齐手段，不是「云端才是主库」 |
| 2 | **不要自己的服务器**：授权、传输、冲突元数据均走提供商 SDK / 系统能力 |
| 3 | **支持 iCloud + 第三方云盘**；**主推 Google Drive 或 Dropbox**（方便 Personal Agent / 脚本操作同一路径；服务全球用户） |
| 4 | **iCloud** 服务 Apple 本机生态；云端 Agent 难直接操作，**不当 Agent 主路径** |
| 5 | 本机永远免费；**一点「开启同步」就付费墙**，未付费不走 OAuth |

## 能力边界（当前）

| 能力 | 定位 |
|------|------|
| 自选本机库、读写 `.md` | 核心 · 已定 |
| 源码编辑 + 切换 / 分栏预览 | 核心 · 已定 |
| **云盘同步** | **核心能力**（非「即将推出」灰显心态）；流程与状态机见 [SYNC.md](./SYNC.md) |
| MCP / AgentBridge | 后续；可与同步解耦灰显 |
| 自建账号 / 自建同步服 / 实时协作 | **明确不做** |

## 提供商矩阵摘要

| 提供商 | 一期 | 定位 | Personal Agent |
|--------|------|------|----------------|
| **Google Drive** | ✅ 主推 | 全球跨平台同步首选 | ✅ 易 |
| **Dropbox** | ✅ 主推 | 全球跨平台同步首选 | ✅ 易 |
| **iCloud** | ✅ 支持 | Apple 本机 / 生态 | ❌ 难（不当 Agent 主路径） |
| OneDrive 等 | 二期 | — | — |
| 自建 WebDAV / 自建服务器 | ❌ | — | — |

一期选择器**仅展示三项**；其余提供商**不灰显占位**，二期再加。主推 Drive / Dropbox 是为出海与 Agent 友好，**不是**国内盘优先策略。

### 冲突与付费（摘要 · 已定）

- **冲突**：禁止静默覆盖；必须弹选——保留本地 / 保留云端 / 两边都留；两边都留文件名用 `原名 (云端冲突 yyyy-mm-dd).md`。
- **付费**：一点「开启同步」就墙；未付费不走 OAuth。

完整流程、状态机、界面清单 → **[SYNC.md](./SYNC.md)**。

## 与用户的一句话

> 笔记始终在你自己的文件夹里。接上 Google Drive 或 Dropbox 后，你的 Personal Agent 也可以读写同一库；接 iCloud 则更适合只在自己的苹果设备之间同步。  
> （应用内需提供至少中英对应文案；跟随系统或设置切换语言。）
